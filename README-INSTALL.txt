INTERACTIVE WORLD MAP — INSTALLABLE IPAD APP (PWA)

This is a complete PWA website folder, not a native .ipa App Store app.
Opening the index.html file from Files will NOT install the app.

TO INSTALL ON IPAD:
1. Upload all files from this folder to an HTTPS web host (e.g. Netlify Drop).
2. Open the published HTTPS address in Safari on your iPad.
3. Tap Share > Add to Home Screen > Add.
4. Launch Interactive World Map from the Home Screen.
5. Open the site online once before relying on offline mode.

QUICK PUBLISH WITH NETLIFY DROP (ON A COMPUTER):
1. Extract this ZIP.
2. Open https://app.netlify.com/drop in a browser.
3. Drag the entire Interactive_World_Map_App folder onto the page.
4. Use the HTTPS .netlify.app link generated after publishing.

NOTE: This package is ready for hosting but has not yet been published.
The country borders are modern approximations for educational use.
